# VisionAI for Home Assistant

VisionAI is an open project to recognize people and vehicles from home security cameras and integrate those events with Home Assistant.

This repository now includes an **MVP starting point** based on the roadmap:

- **MVP scope**: viability spike (Phase 0) + core backend foundation (Phase 1)
- **Focus**: prove recognition quality, define architecture boundaries, and prepare implementation milestones

## Start Here

1. Read the MVP definition: [docs/mvp-scope.md](docs/mvp-scope.md)
2. Review the technical architecture: [docs/architecture.md](docs/architecture.md)
3. Follow implementation setup guidance: [docs/setup.md](docs/setup.md)
4. See complete phased roadmap: [docs/roadmap.md](docs/roadmap.md)

## What is in the MVP

- Clear acceptance criteria for detection quality and latency
- Hexagonal backend module boundaries
- Ports/adapters design for cameras and AI engines
- Delivery plan for database, testing baseline, and Docker Compose target
